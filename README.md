# Letters and Sounds Club

A small browser app for practising British phonics with an early-years reader:
letter names, letter sounds, matching capitals to lower case, picking out every
letter in an unfamiliar word, and spelling a word heard out loud.

Open it, then use your browser's "Add to Home Screen" to run it full screen and
offline. It uses the device's own British text-to-speech voice, so pick an
en-GB voice under "Grown-ups".

Single static page. No tracking, no accounts, no data leaves the device.
